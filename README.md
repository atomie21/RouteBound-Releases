# RouteBound

Official game downloads and signed updates. Game source code is not hosted here.

[Download the latest release](https://github.com/atomie21/RouteBound-Releases/releases/latest)

- **Windows:** extract `RouteBound-Windows.zip` and run `RouteBound.exe`. Keep the whole folder.
- **Linux x86_64:** extract `RouteBound-Linux-x86_64.tar.gz`, open a terminal in its RouteBound folder and run `./RouteBound --browser`. This opens the game in your default browser; Python and Wine are not required. Tested on Ubuntu 22.04, requires glibc 2.35+ and a desktop browser. Keep the terminal open while playing; stop worlds in the menu and press Ctrl+C to close the launcher.

The `*-Update.zip` downloads and `update-stable.json` are compatibility packages for the built-in updater, not the normal first-install downloads. Saves remain outside the application folder. Older Windows builds through 0.2.3 may need one manual installation for the updater fix.
